UNIVERSITY OF MINDANAO DIGOS - CANTEEN INVENTORY SYSTEM

Files:
- index.html + index.js: Login page
- dashboard.html + dashboard.js: Dashboard
- inventory.html + inventory.js: Inventory, search, edit and delete
- add-item.html + add-item.js: Add and edit item form
- style.css: Shared UM red/gold theme
- app.js: Shared inventory/localStorage functions
- assets/um-logo.png: Provided University of Mindanao logo

How to run:
1. Keep all files in the same folder and keep assets/um-logo.png in the assets folder.
2. Open index.html in a browser.
3. Log in using the demo account.

Data storage:
This is a frontend-only version. Inventory data is saved in the browser's localStorage, so add/edit/delete changes persist on the same browser/device.
